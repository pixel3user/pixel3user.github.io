Profile

An engineer who benchmarks before he believes

My work sits at the join between software engineering and empirical evaluation: building LLM systems, then measuring them properly — on real repositories, real terminal workflows, and prompts in the mixed languages people actually type.

What I do

I design and run evaluations for agentic and code-generation models (SWE-bench-style repository tasks, Terminal-Bench workflows), build full-stack LLM prototypes, and release the datasets and tooling so results can be reproduced. My published work, CodeMixBench, tests whether code models still work when prompts mix languages — Hinglish, Spanglish, and Pinyin-English — the way millions of developers naturally write.

Jan 2025 — Apr 2025 · Open source

Open-Source LLM Evaluation Framework & CodeMixBench

A modular evaluation CLI with notebooks, built to benchmark 17 code-generation models on multilingual, code-mixed prompts. Designed for reproducible evaluations and lab use: fixed prompt sets, scripted scoring, and a public dataset release so anyone can re-run the numbers.

  • 6k+ prompts across Hinglish, Spanglish, and Pinyin-English
  • 17 code models evaluated under one harness
  • Dataset + evaluation scripts released (Hugging Face / GitHub)
  • Paper: “Evaluating Large Language Models on Code Generation with Code-Mixed Prompts” (2025), arXiv:2505.05063
PythonLLM evaluationBenchmark designReproducibility

Aug 2025 — Feb 2026 · Applied LLM

Dermatology LLM Prototypes (Chang Gung University)

Full-stack LLM prototypes for dermatology, built in a biotechnology lab under a Taiwan Ministry of Education project — taking a clinical idea from data and prompting through to a usable interface, and on to third-tier recognition in the TCA Startup Competition with team NexAI.

May 2023 — Aug 2023 · Edge ML

TensorFlow Lite Sign-Language Recognition

An edge-optimised transformer model for ASL fingerspelling, deployed with TensorFlow Lite. I collected and augmented 3M frames, improved low-light robustness of detection, and released an edge-optimised model card (ASL-TFLite-Edge) so others can evaluate the trade-offs.

  • 3M frames collected and augmented
  • Low-light robustness improvements
